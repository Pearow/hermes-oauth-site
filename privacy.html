Privacy Policy

Hermes Personal Assistant — operated by Pearow. Last updated: October 17, 2026.

This notice covers the owner's personal Google Calendar integration and this informational website. The assistant is intended for its owner, not public registration.

Information accessed and its purpose

After the owner grants access, the integration accesses calendar-list information, calendar events, and free/busy information. It uses these to display schedules, assist with planning, and create, edit, or delete individual events in selected existing calendars at the owner's request. OAuth credentials and calendar selections are stored to maintain that connection. The integration does not request Gmail access.

Processing, storage, and sharing

The assistant is configured to process Calendar information using a locally hosted AI model rather than a cloud AI model. Authorization credentials, calendar selections, conversation history, event-change drafts, receipts, recovery snapshots, and backups may be stored on the owner's computer.

Google processes Calendar API requests and authorization. When Calendar information is included in a Telegram conversation, Telegram processes those messages under its own policies. Local model processing does not mean that all information stays off external services.

The operator does not sell Google user data or use it for advertising or training AI models. Access is intended for the owner and for operating and maintaining the personal assistant.

Retention, deletion, and revoking access

Local records are retained until removed by the owner. The owner can revoke the app's Google access through Google Account connections. Revoking access prevents continued authorized access but does not automatically delete locally stored history, tokens, drafts, snapshots, or backups. Those copies must be removed separately by the owner. Removing a local copy does not delete the original Google Calendar event.

This website

These static pages contain no application forms, analytics scripts, or Calendar connection. They do not receive Google Calendar content or OAuth tokens. GitHub Pages hosts the website and may process visitor information, such as IP addresses, as described in the GitHub Privacy Statement.

Google API user data policy

Hermes Personal Assistant's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Contact the operator through the website repository's issue page. Issues are public: do not include private messages, calendar information, authorization codes, or credentials.
