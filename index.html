Hermes Personal Assistant

A personal assistant for its owner, available through a private Telegram conversation. It can summarize selected Google Calendar information, search and read Gmail when asked, and prepare concise on-demand briefings.

AI interpretation is performed with a locally run Qwen model. Google and Telegram still process information as part of their services; local model processing does not mean that data never leaves those services or the device environment.

What it can do

  • Read events and availability from the owner's selected Google Calendars. At the owner's request it can create a fully specified individual timed event. Editing or deleting an individual event or occurrence requires a complete preview and confirmation in a later owner turn. No attendees, invitations, bulk changes, or whole-series changes are supported.
  • Search Gmail on request (by default, unread messages in the inbox), read and summarize relevant messages, and include up to five concise email highlights in an on-demand briefing. It does not continuously monitor email.
  • Remove unread status only through a separate, explicitly requested preview-and-later-confirmation workflow for eligible routine promotions/newsletters.
  • Download an attachment only when the owner explicitly requests that specific attachment. Attachments are not opened, executed, extracted, or downloaded automatically.

Google permission note: the Gmail authorization grant permits broader Google account actions than this assistant exposes, including sending and trashing mail. The assistant's supported workflow is not credential-level containment. Calendar and Gmail access is locally authorized for the same owner account.

See the Privacy Policy for data handling details.

Questions or concerns: use the project's public GitHub issues. Issues are public; do not post private email or calendar content, credentials, or authorization codes.
